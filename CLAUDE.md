## Google-specific regeneration

`make prepare-openapi` downloads both official source documents without credentials, then runs `make regenerate`. Source files and overlays live in `specifications/discovery/` and `specifications/interactions/`. Root `original_openapi.json` is generated by composing the sanitized/overlaid sources; do not edit it or `openapi.json`. Keep the root overlay empty. Preserve upstream `Part` and `FunctionResponsePart`; do not restore the old closed Part union or model-ID enum.

The merge script prefixes Interactions components, rewrites references, and preserves per-source authentication plus existing operation names. Its output feeds the bootstrapper so operation security metadata covers both APIs. The Interactions overlay keeps model strings open and maps Speakeasy custom authentication to standard schemes. The pinned bootstrapper infers missing scalar types from constants before applying overlays; keep tag typing in the generic converter. Keep the pinned generator revision with that inference support, since incorrect union decoding can silently lose transcription output. `Client.transcribeAudio` uses beta Interactions on the global endpoint and returns the full generated resource with `outputText` and `wordAnnotations` conveniences. Keep helpers outside GeneratedSources.

`createClient` belongs to the AsyncHTTPClient product. Both factories retain fractional-second dates and upload-header correction; the AsyncHTTPClient default timeout is 20 minutes. `make test-offline` runs stub-based regressions. Live tests require explicit `RUN_LIVE_TESTS=1` and an exported `GEMINI_API_KEY`, and must not be run during ordinary regeneration.
